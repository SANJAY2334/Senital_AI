# apps/

Contains frontend user applications for SentinelAI operators.

- `analyst-workspace/`: Primary web interface for SOC Analysts, Threat Hunters, SOC Managers, SecOps Architects, and CISOs. Implements Incident Story Workspace, Interactive Causal Graph Canvas, XAI Evidence Drawer, NL Copilot Drawer, and Executive Dashboards (HLD Section 5.2, SRS-UI-001..004).
