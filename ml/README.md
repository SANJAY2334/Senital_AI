# ml/
Machine Learning Architecture Subsystems & Pipeline Tools (MLAD Section 10-25, ADR-0009).

- `models/`: Subagent AI models (Isolation Forest, XGBoost Threat Classifier, SHAP Explainer).
- `feature-store/`: Online key-value feature store and offline lakehouse feature store definitions.
- `pipelines/`: Model training, hyperparameter tuning, drift detection, and active learning scripts.
